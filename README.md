# EduCore

## Enterprise Learning Management System

EduCore is an enterprise-level Learning Management System (LMS) designed to provide a centralized platform for students, instructors, and administrators.

### Project Status

Capstone Phase — Sprint 13

### Planned User Roles

- Student
- Instructor
- Admin

### Planned Core Features

- User authentication
- Course management
- Lessons and learning progress
- Assignments
- Quizzes
- Grades
- User management
